# OMNILUXIA OVERRIDE of the vanilla file of the same path.
#
# Two changes, both mechanical - every tier gate and probability table below is
# copied verbatim from the base game file:
#
# 1. PERF (fold): vanilla fires gw_effects.1/.2/.3/.4 as four separate events from
#    yearly_country_pulse, i.e. four trigger passes per country per year. They are
#    folded into one event whose immediate block runs the four original triggers as
#    if-gates instead. common/on_action/00_yearly_country.txt now fires only
#    gw_effects.1.
#
# 2. PERF + BUGFIX (scoping): every one of the 16 every_character scans in the
#    vanilla version is GLOBAL - it walks every living character in the world.
#    That means one country owning a Great Work with an education effect scans
#    (and trains the children of) every other country on the map, every year.
#    Each scan now carries `employer = root`, restricting it to the owning
#    country's own characters. This is the bulk of the saving and also stops
#    foreign courts being trained by someone else's monument.
#
#    If you ever want vanilla behaviour back, delete this file - the base game
#    version takes over again - and restore gw_effects.2/.3/.4 in
#    common/on_action/00_yearly_country.txt.
# ----------------------------------------------------------------------------------------------------------------------
