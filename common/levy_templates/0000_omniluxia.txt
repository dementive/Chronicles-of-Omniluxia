# NOTE: No levy templates should ever have more than 4 entries.
#
# Weights are relative; each template must sum to 1.0.
#
# Pop tier mapping:
#   Basic-tier pops (freemen, tribesmen, serfs) supply basic units:
#   light_infantry, archers, spearmen, axemen, light_cavalry, horse_archers,
#   horse_skirmishers, camels.
#   Advanced-tier pops (citizens, nobles) supply heavy_infantry, heavy_cavalry,
#   chariots, warelephant.
#
# Fallback rule: a unit the country cannot recruit is replaced by another unit of the
# same tier (basic -> light_infantry/archers, advanced -> heavy_infantry). So an
# advanced mount slot reads as heavy infantry until the country has the mount.
#
# Mount access (common/units army_07..12 allow blocks): the trade good (owned or
# imported) OR a culture listed in that unit's inline owner = { } block. The lists are
# mirrored in common/scripted_triggers/OMNI_levy_mount_triggers.txt - keep them in sync.
#
# Horse share targets (light/heavy cavalry, horse archers, skirmishers, chariots):
#   steppe nomads ~50-60%, horse/knight cultures ~30-45%,
#   settled peoples ~10-25%, cave/island/forest peoples 0-15%.
# Every culture group whose homeland has horses, steppe horses, camels or elephants
# (2+ provinces) has a unit here that uses them.
