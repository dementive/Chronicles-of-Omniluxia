# NOTE: No levy templates should ever have more than 4 entries.
#
# Pop tier mapping:
#   Basic-tier pops (freemen, tribesmen, serfs) can only supply basic units:
#   light_infantry, archers, light_cavalry, horse_archers, camels.
#   Advanced-tier pops (citizens, nobles) supply heavy_infantry, heavy_cavalry.
#
# Fallback rule: a unit type the country cannot recruit is replaced by light_infantry
# by the engine. Design templates so the fallback is intentional — if a country
# lacks trade goods or traditions for mounted units, light_infantry fills in.
#
# Chariots are excluded from all templates: they are disabled (enable = no) in the
# base unit file until a military tradition unlocks them. Including them causes most
# countries to silently fall back to light_infantry for that weight slot.
#
# Each template should have one clear lead unit drawn from the basic-tier list,
# so a country with no special trade goods or traditions still fields a coherent army.
#
# Weights are relative; each template must sum to 1.0.
# Mounted units are gated by trade goods OR the culture triggers in
# common/scripted_triggers/OMNI_levy_mount_triggers.txt — keep those lists in sync
# when adding mounted units to a template.
