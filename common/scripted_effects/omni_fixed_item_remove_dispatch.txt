# Strips the _personal / _army layers of an EQUIPPED fixed combat item when the
# item leaves the character (sold, discarded, gifted). remove_character_item used
# to remove only the legacy _modifier, so both halves stayed on forever.
# Fixed item modifier names must be literal at parse time, hence the explicit
# dispatch on var:omni_removed_combat_item instead of $item_ID$_personal.
# CHARACTER scope. The country half is kept when the realm army loadout still
# holds the same item, since that slot applies the same _army modifier.
